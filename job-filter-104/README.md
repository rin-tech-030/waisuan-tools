# 職缺過濾器（適用 104）— 開發與測試說明

免費版 Chrome 擴充套件（Manifest V3）：在 104 職缺搜尋結果中，隱藏你指定的公司與標題關鍵字職缺。

## 以「載入未封裝項目」安裝測試

1. 開啟 Chrome，網址列輸入 `chrome://extensions`。
2. 右上角開啟「開發人員模式」。
3. 按「載入未封裝項目」，選擇本資料夾（`ext-104`，內含 `manifest.json`）。
4. 到 `https://www.104.com.tw/jobs/search/?keyword=工程師` 搜尋，**重新整理該頁**（擴充套件安裝前已開啟的分頁不會被注入）。
5. 結果約 6 秒後才載入；載入後每張卡片右上角會出現「隱藏這家公司」。
6. 修改程式後，在 `chrome://extensions` 按該擴充套件的重新整理圖示，再重新整理 104 頁面。

## 功能

- 卡片按鈕「隱藏這家公司」：以公司 ID（網址 `/company/<id>`）加入黑名單。
- 被隱藏的職缺會收合成一行「已隱藏：…」，旁邊有「顯示」可個別暫時顯示。
- 工具列 popup：本頁已隱藏數量、「暫時顯示全部／恢復隱藏」、開啟設定。
- 設定頁：公司黑名單（可手動新增、改顯示名稱、移除）、標題關鍵字黑名單、匯出／匯入 JSON（匯入為合併）。

## 驗證選擇器

在 104 搜尋頁按 F12 開 Console，貼上 `test-snippet.js` 全部內容執行，會列出卡片數量、每張卡片的職缺編號、標題、公司、公司 ID，以及各自命中的選擇器。有「(無)」代表該欄位選擇器失效。

## 104 改版時要改哪裡

所有選擇器集中在 `content.js` 最上方的 `SELECTORS` 物件（`test-snippet.js` 內有一份相同的，需同步修改）。

## 設計重點

- 104 結果清單是虛擬捲動，同一批節點會被重複使用換內容。因此不用 `display:none` 藏卡片，而是在卡片上標記 `data-jf104` 狀態，由 `content.css` 把內文收合成一行。
- `MutationObserver` 監聽 childList、characterData、subtree 與關鍵屬性；每次變動都重新讀取每張卡片「當下」的公司與標題，並清除舊的隱藏狀態。我們自己修改 DOM 時會暫停監聽，避免無限迴圈。
- 所有文字都以 `textContent` 或 CSS `attr()` 顯示，沒有 `innerHTML`、`eval`，沒有網路請求。

## 權限

- `permissions`：只有 `storage`。
- `host_permissions`：只有 `https://www.104.com.tw/*`。
- `content_scripts.matches`：只有 `https://www.104.com.tw/jobs/search/*`。

## 已知限制（尚未實測）

- 桌機版版面的選擇器是依手機版推測，未實測；用 `test-snippet.js` 確認，必要時修改 `SELECTORS`。
- 虛擬捲動清單的高度可能是固定的，卡片收合後可能留下空白，視 104 實際實作而定。
- 「本頁已隱藏數量」統計的是目前頁面上「已被渲染過」的卡片，尚未捲動到的不會計入。
- 若網址為 `/jobs/search?...`（結尾沒有斜線），不符合 match pattern，不會注入。
- 從其他 104 頁面以站內導覽（不重新載入）進入搜尋頁時，content script 可能不會注入，需重新整理。
- 這個擴充套件沒有在真實的 Chrome 載入測試過（只做了語法與 manifest 檢查）。
