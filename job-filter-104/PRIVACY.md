# 隱私權政策：職缺過濾器（適用 104）

最後更新：2026-10-14

## 一句話版本

本擴充套件**不收集、不傳送、不販售任何資料**。

## 我們不做的事

- 不收集個人資料、瀏覽紀錄、搜尋關鍵字、職缺內容或公司資訊。
- 不發送任何網路請求，不連線到任何伺服器（包含統計、分析、廣告、錯誤回報）。
- 不載入或執行遠端程式碼。
- 不使用 Cookie，不讀取你在 104 的登入狀態或帳號資料。
- 不與任何第三方分享資料。

## 儲存在你瀏覽器內的資料

為了讓過濾功能運作，擴充套件把你自己設定的以下內容，存在瀏覽器的本機儲存空間（`chrome.storage.local`）：

1. 公司黑名單：公司 ID 與你看到的公司顯示名稱。
2. 標題關鍵字黑名單。

這些資料只存在你這台電腦的 Chrome 設定檔內，不會上傳、也不會同步到我們或任何第三方。你可以隨時在設定頁移除項目，或在 Chrome 的擴充功能頁面移除本擴充套件，資料即一併刪除。

「匯出」功能只會把上述兩份清單存成你電腦上的 JSON 檔，由你自行保管；「匯入」只會讀取你主動選擇的檔案。

## 頁面存取範圍

擴充套件只會在 `https://www.104.com.tw/jobs/search/*`（104 職缺搜尋結果頁）執行，在你的瀏覽器內讀取畫面上的職缺標題與公司名稱，用來比對你的黑名單並隱藏符合的職缺。讀取的內容只在記憶體中暫時使用，不會被儲存或傳出。

## 與 104 的關係

本擴充套件為獨立開發的第三方工具，與 104 人力銀行無隸屬、合作或背書關係。

## 政策變更

若未來政策有任何變更，會更新本文件並在擴充套件版本說明中註明。

## 聯絡方式

請透過本擴充套件在 Chrome 線上應用程式商店頁面上的開發者聯絡方式與我們聯繫。
