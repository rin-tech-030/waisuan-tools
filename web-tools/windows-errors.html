Claude Code Windows 中文錯誤訊息對照表

非官方、與 Anthropic 無關、內容由 AI 整理、整理日期 2026-10-14

本頁是獨立實驗的一部分，不是 Anthropic 的產品或文件。遇到問題請以官方繁中排錯頁為準。Claude Code 更新很快，這裡的內容可能隨時過時。

官方排錯頁的對照表只有英文訊息，中文 Windows 使用者看到的字樣很難對得上。這一頁想把它們接起來：把畫面上的字貼進搜尋框，就能找到原因和解法。

使用前先看
  • 「錯誤訊息」欄的字樣都有出處：英文來自官方排錯頁或 GitHub issue；中文只收錄有網頁可查的實際畫面文字，沒有來源的就只放英文原文，不自己翻譯冒充系統訊息。
  • 中文 Windows 上很多訊息仍是英文；同一個錯誤的中文措辭也可能因 Windows 版本而略有不同，搜尋時可只打幾個關鍵字（例如「無法辨識」「TLS」「PATH」）。
  • 「官方頁未涵蓋」的解法都是 GitHub issue 裡使用者自己回報的暫時做法，不是官方修正，請先看副作用說明再決定要不要試。
  • 本表只挑出跟 Windows 有關的項目，沒有逐列轉述官方頁；macOS、Linux 問題請直接看官方頁。
