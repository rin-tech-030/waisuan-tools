# waisuan-tools

歪算（Waisuan）做的小工具。全部免費、開源、不蒐集資料。

| 工具 | 說明 |
|---|---|
| [job-filter-104](job-filter-104/) | Chrome 擴充：在 104 職缺搜尋結果隱藏指定公司與標題關鍵字（資料只存在你的瀏覽器）。[隱私權政策](PRIVACY.md) |
| [web-tools/windows-errors.html](web-tools/windows-errors.html) | Claude Code 在中文 Windows 上的常見錯誤對照表（非官方，與 Anthropic 無關） |
| [web-tools/labor-receipt.html](web-tools/labor-receipt.html) | 勞務報酬單產生器（9A／9B 扣繳與二代健保試算，僅供參考，以國稅局與健保署規定為準） |

另外也有 Apify 上的資料工具：[Taiwan Real Estate Price Registration (實價登錄)](https://apify.com/waisuan/taiwan-real-price-registration)。

內容由 AI 製作。非官方工具，與 104 人力銀行、Anthropic 等無隸屬關係。
